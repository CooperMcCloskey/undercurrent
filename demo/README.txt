Undercurrent demo (static: no Python packages, no repo, no API needed).

Windows (PowerShell), in this folder:
    npx serve -l 8080 .            (needs Node.js)
 or python -m http.server 8080     (needs Python)
then open http://localhost:8080

Mac / Linux, in this folder:  python3 -m http.server 8080   then open http://localhost:8080
